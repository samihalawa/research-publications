## Scope

APOLO documents an inference prototype and proposed evaluation design. FERMED specifies a research architecture and evaluation protocol. Neither manuscript reports a clinically validated diagnostic system. The manuscripts state their implementation boundaries, evidence provenance, limitations and availability of research materials.

The Zenodo records provide the canonical citations. This repository distributes the corresponding manuscript files; it does not contain patient datasets, trained model weights or the private application source repositories.
